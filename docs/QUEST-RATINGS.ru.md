# Наш рейтинг квестов

После подтверждённой сдачи квеста аддон предлагает оценить, понравился ли сам
квест: зелёный палец вверх или красный палец вниз. Открытие экрана награды без
сдачи, отказ от квеста и закрытие окна оценки не создают голосов.
Под названием показана цель задания, сохранённая до его удаления из журнала.
Для повторного открытия последнего квеста она остаётся в SavedVariables.

В этом же окне есть «Пожаловаться на озвучку». Кнопка открывает отдельную
форму жалобы для записи этого квеста; жалоба не меняет оценку самого задания.

## Управление

- `/cq options` → «Предлагать оценить квест после сдачи» отключает автоматическое окно.
- `/cq rate` открывает последнюю сданную задачу для изменения оценки.
- `/cq rate 9851` открывает оценку указанного квеста; доступен также `/cqrate 9851`.
- Несколько быстрых сдач ставят окна в очередь. В бою и во время смерти новое
  окно откладывается. Двойной клик не оценивает следующий квест случайно.

Настройка сохраняется в SavedVariables и браузерном расширении; её последнее
значение имеет приоритет над старым снимком игры после F5. Ручная оценка
остаётся доступна при отключённом автоматическом окне.

## Хранение и подсчёт

Рейтинг CatQuest собирается отдельно от оценок внешних сайтов и жалоб на голос.
Одна установка расширения имеет отдельный идентификатор голосования. Для пары
«квест + версия клиента» хранится один актуальный голос: смена мнения заменяет
его. Разные персонажи одной установки не добавляют повторные голоса.

Отправляются ID квеста, версия клиента, язык клиента и выбор `1` или `-1`.
В аддоне **0.10.68** и расширении **0.6.39** при включённых метриках к действию
добавляются ник, игровой сервер и GUID персонажа. При выключенных метриках
или запрете передачи персонажа оценка остаётся анонимной. Состояние проверяется
при приёме голоса расширением и повторно перед HTTP-отправкой. Анонимный голос
не получает имя при последующем включении метрик; старые оценки не дополняются
именем по догадке. Аккаунт игры и его учётные данные не передаются.
Голос отправляется только
после нажатия игроком, в том числе при выключенной телеметрии или озвучке.
Расширение сохраняет неподтверждённую отправку и повторяет её после восстановления
сети, перезапуска браузера или через пятиминутный таймер. Повторная доставка
не увеличивает число голосов.

Персонаж фиксируется на момент нажатия в игре. Отложенная отправка после смены
героя использует исходный снимок, а не последнего персонажа браузерной сессии.
Расширенный пакет передаётся только при поддержке нового протокола расширением;
старые пакеты продолжают приниматься анонимно.

`quest_ratings` хранит актуальный голос и его последнюю атрибуцию;
`quest_rating_events` — историю явных действий с уникальным `event_id`,
персонажем при разрешённой передаче, временем отправления из клиента
`submitted_at` и временем получения `received_at`. Повтор одного события не
создаёт новую строку. Несколько персонажей одной установки по-прежнему не
увеличивают число голосов за один квест. Публичный API выдаёт только агрегаты.

На backend считаются количество лайков, дизлайков, общее число голосов и доля
положительных оценок. Для квеста без голосов процент отсутствует, а не равен нулю.
Это один голос от установки расширения; проверка личности человека или
подтверждение игровым сервером не заявляются.

## API

- `POST /api/v1/quest-voters` — выдать отдельный токен голосующего.
- `POST /api/v1/quest-votes` — сохранить или заменить подписанный голос.
- `GET /api/v1/quest-ratings/9851?client=3.3.5a` — независимая сводка одного квеста.
- `GET /api/v1/quest-ratings?client=3.3.5a&min_votes=5&limit=50` — список с фильтром
  по минимальному числу голосов. Поддерживается `offset`.

Таблицы backend: `quest_rating_voters`, `quest_ratings`, `quest_rating_events`. Сырые голоса и токены
не выдаются публичным API; токены в базе хранятся в виде хеша.

Приватная проверка последних действий:

```sql
SELECT quest_id, vote, character_name, character_realm, character_guid,
       datetime(submitted_at, 'unixepoch') AS submitted_utc,
       datetime(received_at, 'unixepoch') AS received_utc
FROM quest_rating_events ORDER BY received_at DESC LIMIT 20;
```

`submitted_at` — сообщённое клиентом время, `received_at` — время backend.
Ник передаётся клиентом, а не подтверждается игровым сервером.
