# CatQuest online — инструкция для игрока

Этот набор работает через браузер Lasthavens и сервер озвучки. Интернет
нужен во время игры.

## Что внутри

- `CatQuest-0.10.32.zip` — WoW-аддон;
- `CatQuest-Lasthavens-0.6.30.zip` — Chrome-расширение.

## Установка

1. Распакуйте `CatQuest-Lasthavens-0.6.30.zip` в отдельную постоянную папку.
   Не удаляйте эту папку после установки.
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите распакованную
   папку расширения.
5. Откройте менеджер CatQuest через кнопку расширения.
6. Нажмите «Импорт ZIP» и выберите `CatQuest-0.10.32.zip`.
7. Убедитесь, что аддон CatQuest включён в менеджере.
8. Откройте игру на `https://lasthavens.com/play` и перезагрузите страницу.

После этого готовые дорожки будут играть сразу. Если дорожки ещё нет,
расширение отправит запрос на сервер, а звук появится после генерации.

## Обновления

По умолчанию менеджер получает стабильные версии. Если игрок хочет получать
beta-версии, включите в разделе «Обновления» пункт «Получать свежие версии
раньше релиза», затем нажмите «Проверить обновления».

Обновление самого Chrome-расширения скачивается архивом: распакуйте его поверх
старой папки с заменой файлов и нажмите «Перезапустить расширение» на странице
менеджера. Chrome не разрешает расширению молча заменить собственные файлы.

## Важно

- Этот комплект — online-версия. Для игры без Интернета нужен local-комплект
  с отдельным voice-pack аддоном.
- Не удаляйте папку расширения и не меняйте её расположение без необходимости.
- Раздел «Учетная запись озвучки» находится внизу менеджера и свернут по
  умолчанию. Он нужен для восстановления настроек после переустановки.
