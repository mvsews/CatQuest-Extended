# CatQuest 1.1.2: функции и перенос на CatQuest Extended 3.3.5a

Сверено 13.11.2026 с [официальным списком изменений 1.1.2](https://www.curseforge.com/wow/addons/catquest/files/9574043) и скачанным архивом `CatQuest-1.1.2.zip`. Состояние нашего аддона — **0.10.57**. «Есть» ниже означает наличие кода; поведение, для которого указана проверка в игре, пока не подтверждено игровым тестом.

Оригинал предназначен для WoW Forever 1.60.1 (`Interface: 16001`), наша сборка — для 3.3.5a (`Interface: 30300`). Поэтому перенос означает реализацию функции для наших API и данных, а не копирование Lua-файла оригинала.

## Приоритет для нашей версии

Обновление P1: в **0.10.59** перенесены [все совместимые сценарии Мастера](DUNGEON-MASTER.ru.md):
19 карт, 183 встречи, 670 событий и 669 оригинальных записей. Сессии, боевой лог,
квестовые/предметные условия, залы и повторные заходы проверены на Lua 5.1.
Ниже таблица сравнения фиксирует исходную базу 0.10.57; игровой прогон ещё предстоит.

Приоритет учитывает пользу для обычной игры, размер работы и то, сколько следующих функций можно построить на общем коде.

| Приоритет | Что делать | Почему сейчас | Результат первой итерации |
| --- | --- | --- | --- |
| **P0** | Проверить в игре уже выпущенные исправления: призрак, fallback с подзоны на зону, сохранение масштаба/позиции и остановку звука. | Это исправления поведения, которым игрок сталкивается постоянно. Код уже есть, но без игрового прогона нельзя считать задачу закрытой. | Короткий тестовый маршрут и список фактических ошибок. |
| **P1** | Сделать общий каркас Мастера подземелий: сессия инстанса, `mapID`, вход/выход, подзона, очередь реплик и состояние «жив/мертв/вайп». | Это самая полезная из крупных отсутствующих функций и основа сразу для пролога, повторного захода, подводок и развязок. | Один пилотный инстанс с вступлением и одной подводкой, без попытки сразу покрыть все 28 подземелий. |
| **P1** | Добавить детектор босса 3.3.5a и журнал прохождения для пилота. | Без него невозможно корректно повторять сценарий после сброса и запускать реплики на пуле/победе. В 3.3.5a нужен `COMBAT_LOG_EVENT_UNFILTERED` или интеграция с DBM/BigWigs; современные `ENCOUNTER_*` из оригинала переносить нельзя. | Надёжное различение пулов, побед, вайпа и повторного пула уже убитого босса в одном инстансе. |
| **P1** | Перенести и озвучить один полный сценарий подземелья. | Код без текста и аудио не даст игроку новой функции. Один законченный инстанс быстрее выявит ошибки очереди и таймингов. | Пролог → зал → пул → победа, плюс повторный заход через 30 минут. |
| **P2** | Приглушение игры на весь бой с боссом. | Функция полезна, но её детектор и восстановление громкости зависят от P1. | Ползунок для музыки/окружения с безопасным восстановлением после боя, смерти, выхода и `/reload`. Не обещать выборочное приглушение DBM/BigWigs, пока не проверены их каналы. |
| **P2** | «Лапка»: обмен между CatQuest, подсказка, группа, гильдия и `/cq paw`. | Реализуется отдельно и не помогает озвучке. Полезна как социальная функция, но не влияет на чтение квестов и лора. | Обмен приветствиями между двумя клиентами одного сервера, настройка скрытия и список знакомых. |
| **P3** | Значок «Лапки» над nameplate и передача полного пути файла в серверный отчёт. | Это косметика и диагностика. У значка есть дополнительные ограничения старого nameplate API; путь уже можно восстановить по хешу и локальному индексу. | Делать только после проверки основной «Лапки» и необходимости в более подробном отчёте. |

Коротко: первая разработческая ветка должна быть `DungeonSession → BossDetector → один полный инстанс`. Ползунок приглушения подключается после неё. «Лапку» разумно делать отдельной параллельной небольшой веткой, если появятся два клиента для проверки.

## Новое именно в 1.1.2

| Функция оригинала | У нас в 0.10.57 | Можно ли сделать на 3.3.5a | Что нужно / граница |
| --- | --- | --- | --- |
| **«Лапка»: обнаружение других игроков с CatQuest.** Невидимое приветствие игрокам своей фракции рядом, в группе и гильдии; возможность скрыть себя. | Нет | **Да, внутри одного игрового сервера, если он пропускает аддонные сообщения.** | Сначала проверить доставку `SendAddonMessage` / `CHAT_MSG_ADDON` между двумя клиентами. Затем сделать протокол, ограничение частоты сообщений и настройки приватности. Оригинальный `Paw.lua` использует более новый `C_ChatInfo`; его сетевой код нужно адаптировать. Игроков на *другом* сервере аддонными сообщениями обнаружить нельзя. |
| **«Лапка»: строка в подсказке, счётчик в группе, `/cq paw`, список знакомых.** | Нет | **Да.** | Сначала сделать обмен сообщениями; затем подсказку `GameTooltip`, учёт участников группы, сохранение знакомых и команду. Показ зависит от того, получил ли наш аддон ответ другого игрока. |
| **«Лапка» над полоской здоровья игрока.** | Нет | **Возможно с ограничениями.** | У оригинала привязка к `C_NamePlate.GetNamePlateForUnit`. Для 3.3.5a потребуется отдельная работа со старыми nameplate-frame; на кастомном клиенте проверять в игре. Подсказка и счётчик могут работать и без значка над головой. |
| **Мастер подземелий: повторный заход через ≥30 минут и реплика «снова».** | Нет. Есть только короткий [лор инстанса при входе](PLACES-INSTANCES-PLAN.ru.md), это другая функция. | **Да, после создания самого Мастера.** | Нужны сессии по ID инстанса, время выхода/возврата, сохранение пройденных сцен. У оригинала порог сессии и пролога — 30 минут (`Dungeon.lua`). Наше постоянное `placesHeard` не подходит для сессии подземелья. |
| **Мастер распознаёт немедленный сброс подземелья по повторному бою с уже убитым боссом.** | Нет | **Да, но нужен другой детектор боя.** | В оригинале используются `ENCOUNTER_START`, `BOSS_KILL`, `ENCOUNTER_END`. Для 3.3.5a сначала собрать таблицу боссов/ID и определять бой и победу по боевому логу либо проверенному интерфейсу DBM/BigWigs. Затем создавать новую сессию при повторном пуле убитого босса. Ложные срабатывания и вайпы проверить в игре. |
| **Подводки к боссам при английских именах залов; исправление залов Стратхольма на русском.** | Нет: нет сценариев Мастера и привязки его реплик к залам. | **Да, вместе с Мастером и контентом.** | Таблица `enUS → ruRU` для названий подзон 3.3.5a, нормализация `е/ё`, отдельные соответствия для Стратхольма. Имена и ID из Forever нельзя принимать за данные нашего клиента без сверки. [Снимки AreaTable ruRU/enUS](places/source/) уже есть как заготовка. |
| **Ползунок «Бой с боссом: игра тише, %» на весь бой.** | Нет. Наш `duck` понижает музыку и окружение только пока звучит дорожка CatQuest. | **Частично.** | Нужен надёжный детектор начала/конца боя, сохранение и восстановление CVars при смерти, выходе и `/reload`. Можно приглушать музыку и окружение на весь бой. Обещать, что *все* звуки игры станут тише, а DBM/BigWigs/WeakAuras останутся прежними, нельзя без проверки их каналов: общий CVar канала приглушит и чужой аддон, если он играет через тот же канал. В оригинале логика завязана на `ENCOUNTER_START/END` и собственный звуковой маршрут (`Duck.lua`). |
| **Призрак не запускает лор мест при беге от кладбища.** | **Есть.** Наш вариант также не отправляет запрос места на сервер, не отмечает его прослушанным и убирает текущий/ожидающий лор места после смерти. | Сделано | [Books.lua](../CatQuest/Books.lua): `UnitIsDeadOrGhost`, `PLAYER_DEAD`, `PLAYER_ALIVE`, `PLAYER_UNGHOST`. Нужен тест: пройти призраком через новую подзону, воскреснуть и убедиться, что она не отмечена прослушанной до живого посещения. |
| **`/cq report` показывает файл книги или рассказа.** | **Есть с отличием.** Команда открывает нашу форму жалобы; в ней видны название и имя OGG-файла. На сервер уходит ID/хеш, не строка пути. | Сделано в интерфейсе | [Feedback.lua](../CatQuest/Feedback.lua). Проверить в игре две строки формы и отправку жалобы. Если нужен именно путь файла в серверном отчёте, расширить протокол отдельно. |

## Что уже было до 1.1.2 и что есть у нас

Это не новые пункты релиза 1.1.2, но они помогают понять общую картину. [Релиз 1.1.0](https://www.curseforge.com/wow/addons/catquest/files/9568751) ввёл самого Мастера подземелий для 28 подземелий; версия 1.1.2 улучшила его повторные заходы и названия залов.

| Возможность | Состояние у нас | Отличие |
| --- | --- | --- |
| Озвучка квестов, сдачи, книг и лора мест | Есть | Треки и покрытие зависят от нашего локального пака или online/hybrid-сервера; набор контента не равен Forever. |
| Очередь, история, кнопка «Прочесть», автоперелистывание книги | Есть | Реализовано отдельно для 3.3.5a. |
| Говорящая голова, субтитры, масштаб и позиция | Есть частично | Окно и субтитры есть; портрет статический, а не 3D-модель оригинала. |
| Выбор звукового канала, `Stop`, звук при сворачивании | Есть частично | Доступны каналы клиента 3.3.5a. Здесь нет `StopSound(handle)` оригинала: для игрового звука применяются обходные способы, для companion — отдельная команда остановки. Гарантировать мгновенную остановку на каждом варианте клиента нельзя. |
| Лор инстанса при входе | Есть для части инстансов | Это одна история места, без подводок/развязок боссов и журнала прохождения. [План и текущие данные](PLACES-INSTANCES-PLAN.ru.md). |
| Мастер подземелий: пролог, подводка, бой, победа, квестовая зацепка | Нет | Нужны сценарии, идентификаторы и аудио; оригинальный модуль ожидает `CatQuestDungeonData` из **CatQuest Books & Lore 1.2.0**. У нас такого набора нет. |

## Границы и порядок работы

**Можно перенести:** обмен «Лапки» на одном сервере, подсказку и счётчик; сценарии Мастера с отдельными данными и детектором боссов для 3.3.5a; переводы залов; частичное приглушение на время боя.

**Нельзя перенести один в один:** современный код nameplate и encounter-событий из интерфейса 1.60.1, обнаружение игроков на другом сервере, точную избирательную громкость разных звуков внутри одного общего канала через CVar. Это ограничения способа реализации, а не запрет на всю функцию.

Предлагаемый порядок:

1. Проверить в игре два уже выпущенных исправления: призрак и имя файла в форме.
2. Реализовать «Лапку» на двух клиентах одного сервера: сначала обмен, подсказка, группа и настройка скрытия; значок над головой — после отдельной проверки nameplate клиента.
3. Сделать пилот Мастера в одном подземелье: реестр боссов 3.3.5a, сценарий, аудио, реакция на бой/победу/вайп. После этого добавить повторный заход через 30 минут, сброс и соответствия залов.
4. Протестировать приглушение на одном боссе вместе с DBM/BigWigs; только после проверки каналов решать, какие звуки безопасно включать в ползунок.
