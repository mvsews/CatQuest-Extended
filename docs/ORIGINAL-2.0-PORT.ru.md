# Перенос функций CatQuest 2.0

Наша версия аддона теперь `2.1.1`. Код оригинального CatQuest 2.0 не копируется напрямую: оригинал рассчитан на WoW Forever 1.60.1, а эта сборка — на WoW 3.3.5a и серверный/браузерный мост.

## Перенесено

- Для квестов, сдач, книг, историй мест, Мастера подземелий, диалогов NPC и историй NPC есть режимы `Всегда`, `Один раз на аккаунт` и `Не озвучивать автоматически`.
- Режим `Один раз` хранит услышанные ключи в `CatQuest335DB`, поэтому правило действует между персонажами аккаунта. Ручные кнопки «Озвучить», `/cq replay` и `/cq test` остаются доступными.
- `/cq mark` и кнопка `!` помечают текущую дорожку без остановки. Метка сохраняет квест/тип/название/секунду и открывает обычную форму жалобы для уточнения причины.
- Метки и выбранные режимы попадают в отладочный отчёт `/cq log` и окно «Отладка».
- Версия аддона и TOC подняты до `2.1.1`; сохранённые настройки мигрируют с прежней схемы без сброса позиции окна и звукового канала.

## Не переносится один в один

- Современная API оригинала для 1.60.1, 3D-головы и системных событий Forever.
- Автоматическое определение фактической слышимости: клиент 3.3.5a не подтверждает, что `PlayMusic` действительно вывел звук. Для этого остаются текущие readiness-проверки и диагностический журнал.
- «Голос актёра из игры» из пакета CatQuest Voices нельзя автоматически использовать в нашем серверном паке: это отдельные аудиофайлы и другая база NPC. Их можно только выборочно импортировать после проверки лицензии и соответствия текста.
