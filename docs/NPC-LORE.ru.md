# Истории именных существ Запределья

## Учёт для серверной части

Полный рабочий реестр среза production находится в приватном backend:
`backend/docs/private/NPC-LORE-REGISTRY.ru.md`, рядом — одноимённый JSON.
Для каждого NPC он показывает местность, ID, источник, наличие текста в аддоне,
синхронизацию серверного каталога и фактическую готовность точного аудио.
У старых рассказов без фиксированного рассказчика варианты пола проверяются отдельно.

Список ещё не добавленных существ ведётся в
[npc-lore-planned.json](npc-lore-planned.json): ближайшая подборка — Кольцо Крови
в Награнде, затем именные цели охоты Эрнестуэя в Тернистой долине. Это очередь
кандидатов, а не обещание, что истории уже написаны или озвучены.

После изменения текстов `scripts/export_npc_lore.py` обновляет полный серверный
индекс `backend/npc_lore_registry.json` и каталог предварительной озвучки.
На сервере `python backend/npc_lore_registry.py --project-root /srv/CatQuest`
пересобирает документ из SQLite и файлов без запуска генерации.
Реестр отмечает дату среза и сверяет NPC-исходники с опубликованным beta-архивом.

## Первая подборка, 0.10.63

Добавлены в аддон 0.10.63 для клиента 3.3.5a. Это короткие рассказы по
квестовым текстам; отдельные биографии этим зверям не приписываются.

| NPC | ID | Местность | Основа истории |
| --- | --- | --- | --- |
| Камневзор | 18648 | Лес Тероккар | Старый василиск, кровь которого Ша'нир просит для лечения Залии; задание 10020 |
| Потрошительница | 18257 | Награнд | Мать ветрухов со слов Фитца, трофей — глаз; задание 9856 |
| Бантар | 18259 | Награнд | Самка копытня со стадом у Ошу'гуна, трофей — рог; задание 9851 |
| Хол'стяк | 18258 | Награнд | Король талбуков со слов Гарольда Лейна, трофей — копыто; задание 9859 |

При включённых историях NPC рассказ запускается по выбранному в настройках
событию: выбор цели или убийство. Для ручного прослушивания выделите нужного
NPC и введите `/cq npc`. Окно показывает имя, текст, портрет или значок;
доступны «Стоп» и «Пожаловаться». Постоянного сканирования всех мобов рядом нет.

Каждый текст целиком помещается в сообщение браузерному мосту (до 800 байт
вместе с заголовком). Для новых рассказов задан постоянный голос рассказчика,
поэтому пол игровой модели не меняет ключ заранее подготовленной записи.
История описывает зверя, а не произносится от его лица.

Источники: [Камневзор](https://warcraft.wiki.gg/wiki/Stonegazer),
[лекарство для Залии](https://www.wowhead.com/tbc/quest=10020/a-cure-for-zahlia),
[охота на ветрухов](https://www.wowhead.com/tbc/ru/quest=9856),
[охота на копытней](https://www.wowhead.com/tbc/ru/quest=9851),
[охота на талбуков](https://www.wowhead.com/tbc/ru/quest=9859).

## Предварительная озвучка

`PYTHONPATH=.tmp/lua-runtime python scripts/export_npc_lore.py` экспортирует
новые рассказы в серверный `npc_lore_catalog.json`. Voice API готовит по одной
отсутствующей записи, когда очередь запросов игроков пуста. Сохраняются
обычные ограничения бюджета и количества генераций; неудачная запись
повторяется не раньше чем через шесть часов. До окончания подготовки историю
можно запросить обычным способом — она попадёт в очередь озвучки.

Наличие текста в каталоге означает поддержку NPC аддоном. Готовность аудио
проверяется отдельно по серверному кэшу.
