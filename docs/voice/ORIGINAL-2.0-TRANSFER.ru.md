# Перенос аудио CatQuest Voices 2.0.0

Проверено `2026-11-18`. Источник — [CatQuest Voices 2.0.0](https://www.curseforge.com/wow/addons/catquest-voices/files/9667108), файл `CatQuest_Voices-2.0.0.zip`, лицензия CC BY-NC-SA 4.0, автор Cathey / daniilcathey.

## Правило сопоставления

- сравнивались записи `Index.lua` оригинала и `CatQuestExtended_Voices/Index.lua`;
- ID принимался только если он есть в нашем индексе и в каталоге AzerothCore/TrinityCore 3.3.5a;
- текст всех доступных реплик (`DETAIL`/основная, `COMPLETE`/`t`) сравнивался после удаления разметки и таймингов;
- существующие OGG не перезаписывались;
- ID с отличиями текста или только Forever-вариантами не переносились.

## Результат

- совпало по тексту: **5 485 ID**;
- за основу взят полный ранее собранный community-пакет: **13 093 OGG** для **5 752 ID**;
- совместимых новых путей из оригинала 2.0.0, которых не было в полном пакете: **0**;
- существующие OGG не перезаписывались;
- в сравнении файлов оригинал содержит **118** отсутствующих у нас сигнатур,
  относящихся к **87 ID**;
- из этих ID только **1698** и **1794** есть в каталоге 3.3.5a, и оба уже
  покрыты нашим пакетом; новые файлы — варианты NPC
  `1698_n7315.ogg` и `1794_t_n6179.ogg`, а не новые квестовые тексты;
- остальные **85 ID** отсутствуют в каталоге 3.3.5a и относятся к контенту
  WoW Forever/другой версии клиента; ID `79677` — один из них и не переносился;
- после объединения эффективное покрытие каталога 3.3.5a: **4 344 ID**, расхождения с прогрессом: **0**;

Индекс аддона не заменялся: в нём остаётся наш контент 3.3.5a и дополнительные варианты NPC. Обновлена версия voice-пака до `2.0.0-extended.1`. Финальный архив: `dist/CatQuestExtended_Voices-2.0.0-extended.1.zip`, SHA-256 `cb9dca5a49f9430524d5ec2a565b91e27a271b7bbe46daa7fe492ca9854f4b8d`.

Большие OGG-файлы намеренно остаются вне истории Git и попадают в собираемый архив voice-пака.
