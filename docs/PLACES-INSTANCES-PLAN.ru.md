# План озвучки зон, подземелий и рейдов

Это отдельный объём внутри place-lore. Цель — чтобы при первом входе игрока
озвучивалось не только открытое место, но и сам инстанс: подземелье, рейд,
сценарная зона или поле боя, если для него есть понятное описание в мире
3.3.5a.

## Что покрываем

- все открытые зоны и подзоны из `AreaTable` 3.3.5a;
- классические подземелья и рейды;
- подземелья и рейды The Burning Crusade;
- подземелья и рейды Wrath of the Lich King;
- зоны «Пещер Времени» и другие инстансы, которые клиент показывает отдельным
  названием;
- при необходимости — отдельные крылья/сценарии внутри одного инстанса.

Список не берём из одного меню поиска подземелий: источником истины будет
объединённый реестр `AreaTable`/DBC и проверенные названия русского клиента.
Названия из списка на скриншоте — примеры записей, а не отдельный ограниченный
перечень.

## Как это работает в игре

1. На `PLAYER_ENTERING_WORLD`, `ZONE_CHANGED_NEW_AREA` и после загрузки карты
   аддон получает `GetInstanceInfo()` и `GetRealZoneText()`.
2. Для инстанса используется стабильный ключ `instance:<mapID>`, а не только
   отображаемое имя: так одинаковые названия и разные уровни сложности не
   смешиваются.
3. Если `mapID` недоступен, используется проверенный псевдоним русского имени
   зоны.
4. При первом посещении в общей очереди проигрывается короткое вступление
   места. Повторный вход молчит; `/cq place`/кнопка миникарты повторяют его
   вручную.
5. Очередь места не перебивает текущий квест или реплику NPC и не создаёт
   отдельное окно с ложным `ID` квеста.

## Формат данных

Добавить отдельный источник `docs/places/instances.json` либо включить записи
в общий генератор place-lore:

```json
{
  "map_id": 543,
  "zone": "Бастионы Адского Пламени",
  "zone_en": "Hellfire Ramparts",
  "kind": "dungeon",
  "expansion": "TBC",
  "text": "Бастионы Адского Пламени ...",
  "sources": ["quest 10278 (ruRU)", "https://warcraft.wiki.gg/wiki/Hellfire_Ramparts"],
  "status": "todo",
  "notes": ""
}
```

Генератор должен строить:

- `CatQuest/PlaceData.lua` или отдельный `InstanceData.lua` для соответствия
  `mapID` и хеша дорожки;
- строки статуса и очередь озвучки для online;
- индекс и OGG в `CatQuestExtended_Voices` для local;
- сводку покрытия: всего, написано, озвучено, пропущено и причина пропуска.

Для обычной зоны и инстанса используется один контракт дорожки книг/мест:
online получает `/api/v1/book/<hash>`, local играет тот же hash из voice-pack.
Новый сетевой протокол для инстов не нужен.

## Не смешивать с репликами NPC

Вступительный рассказ о месте — это один трек при входе. Реплики монстров,
сцен и сопровождаемых NPC в подземельях остаются отдельным этапом: для них
нужны отдельный поиск по `creature_text`/`broadcast_text` и другая логика
событий.
