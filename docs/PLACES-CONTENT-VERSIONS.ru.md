# Версии контента для локаций

Локации и подзоны хранятся не только по названию, но и по контентному срезу
клиента. Для текущего addon это `3.3.5a`; в будущем отдельный addon может
поставляться со срезом `4.3.4` и своим `PlaceLore.lua`.

Правила:

- одинаковый текст получает одинаковый hash и может использоваться всеми
  версиями контента;
- если в зоне изменились события, фракции или сам текст, создаётся новая
  запись с новым `content_version` и новым hash;
- в `place_requests.client_version` бэкенд сохраняет версию клиента, поэтому
  спрос по Степям 3.3.5 и Степям 4.3.4 не смешивается;
- зона и подзона — разные измерения: запрос «Окаянная лощина» не считается
  запросом всей зоны;
- при сборке `PlaceLore.lua` можно указать
  `python tools/voice_places.py lua --content-version 3.3.5a`: попадут общие
  записи и записи выбранного среза.
- файлы общих дорожек сохраняют совместимое имя `<area_id>.ogg`, а дорожки
  конкретного среза получают имя `<text_hash>.ogg`; поэтому одинаковый
  `area_id` в клиентах 3.3.5a и 4.3.4 не может перезаписать чужую озвучку;
- при обновлении старые версионные файлы с именем `area_id.ogg` мигрируются
  в hash-имя командой `python tools/voice_places.py migrate --out ...`.

Файл зоны может иметь `content_version: "shared"`, если текст не менялся между
клиентами, или конкретную версию (`3.3.5a`, `4.3.4` и т. п.), если он описывает
историческое состояние зоны.
