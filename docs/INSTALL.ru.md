# Установка клиента

## Online-вариант

1. Скопируйте папку `CatQuest` в `Interface/AddOns`.
2. Установите Lasthavens Addon Manager как распакованное расширение браузера.
3. В менеджере укажите URL backend, который предоставил оператор сервера.
4. Перезагрузите страницу игры и выполните `/reload` в WoW.

Online-вариант получает аудио по запросу и не требует полного voice-pack на
клиенте. Секреты и служебные настройки backend игроку не нужны и не должны
передаваться в addon или расширение.

## Local-вариант

1. Скачайте [CatQuestExtended_Voices.zip](https://catquest.mvse.ws/downloads/CatQuestExtended_Voices.zip).
2. Скопируйте папку `CatQuest` в `Interface/AddOns`.
3. Распакуйте рядом папку `CatQuestExtended_Voices`.
4. Выполните `/reload`.

Local-вариант не использует интернет, backend или браузерное расширение. В нём
доступны только дорожки, которые входят в установленный локальный voice-pack.

## Hybrid-вариант для обычного WoW

1. Установите `CatQuest`; `CatQuestExtended_Voices` можно добавить для
   готовых локальных дорожек.
2. Запустите `CatQuest-Client.cmd sync --wow-dir "путь\к\WoW"`.
3. Выполните `/reload`.

Утилита обновляет `CatQuest`, скачивает готовые дорожки Voice API и создаёт
локальный `CatQuest335_ServerVoices`. Локальный voice-pack имеет приоритет, а
серверные дорожки используются как fallback. Для ещё не готовой дорожки:

```text
CatQuest-Client.cmd request 606 DETAIL --wow-dir "путь\к\WoW"
```

После успешного запроса снова выполните `/reload`. Команда `watch` может
периодически синхронизировать кэш и обработать сохранённый список
`CatQuest335DB.missing`.

Для live-режима без браузера установите зависимости и запустите companion:

```powershell
python -m pip install -r client\requirements.txt
CatQuest-Client.cmd companion --wow-dir "C:\Games\World of Warcraft\_retail_"
```

`CatQuestCompanion` передаёт текст через цветные клетки в левом верхнем углу,
а внешняя программа запрашивает OGG у Voice API и проигрывает его через
`pygame`. Если WoW уже запущен, после установки выполните `/reload`; для
оконного режима можно указать `--x` и `--y`. Вызов `PlaySoundFile` по-прежнему
не перехватывается — companion получает именно текст запроса от CatQuest.

## Lasthavens Desktop для Windows

1. Установите [Lasthavens Windows Desktop](https://lasthavens.com/guides/windows-desktop-app).
2. Скачайте готовый [CatQuest Hybrid для Windows](https://quester.mvse.ws/downloads/CatQuest-Hybrid-Windows.zip), распакуйте архив и запустите `CatQuest-Hybrid.exe`.
   Python и `pip` не нужны: они уже встроены в exe.
3. Утилита сама найдёт `Lasthavens.exe`,
   установит `CatQuest` и `CatQuestCompanion` в
   `%APPDATA%\Lasthavens\AddOns`, а затем будет проверять обновления аддона.
4. После установки или обновления выполните в Lasthavens `AddOns` → `Reload game`.

Для Desktop-браузерное расширение Lasthavens не требуется.

## Проверка в игре

```text
/reload
/cq stop
/cq test 606
```

Полезные команды:

```text
/cq test <id>       тестовая озвучка
/cq stop            очистить очередь и остановить companion; звук SFX может не прерваться в 3.3.5
/cq next            пропустить текущую
/cq replay          повторить последнюю
/cq auto            включить или выключить автоматический режим
/cq subtitle on     включить субтитры
/cq subtitle off    выключить субтитры
```

Для проверки остановки в 3.3.5 откройте `/cq options` → «Звук» → «Звуковой
канал» → «Музыка». Готовая дорожка в этом режиме заменяет фоновую музыку игры;
`/cq stop` и «Далее» прерывают её. Озвучка, которую сервер ещё генерирует, и
динамический диалог NPC пока идут через SFX и могут не прерваться мгновенно.
Смена канала останавливает текущую очередь. Прослушивание главы ставит её
завершённые задания в последовательную очередь, даже если очередь отдельных
диалогов отключена в настройках. Повторное нажатие не добавляет копии заданий.
Начиная с 0.10.70 завершающие реплики нескольких быстро сдаваемых квестов тоже
идут последовательно: задержка приветствия не теряет первую реплику, а обычное
закрытие окна после получения награды не удаляет её. Новые приветствия ждут
окончания этой очереди. «Стоп» по-прежнему очищает её; закрытие экрана награды
без получения при включённом «Останавливать при закрытии окна» отменяет превью.
В расширении 0.6.38 опрос готовности привязан к текущей дорожке: ранее запрошенный
квест не перехватывает запуск другого, а полученный из кэша файл не выдаётся повторно.

Истории мировых боссов и других NPC всегда открывают окно с именем, текстом
и кнопкой «Стоп», в том числе при отключённой общей «говорящей голове».
В обычных репликах собеседника с 0.10.71 имя игрока и обращения к его классу
удаляются до запроса аудио. Запись и её кэш становятся общими для разных
персонажей; имя самого NPC и сведения о классах в содержании рассказа сохраняются.
Портрет берётся только у соответствующего NPC; если подходящая цель недоступна,
показывается значок босса. То же окно используется Мастером подземелий.
Кнопка «Пожаловаться» в правом верхнем углу открывает форму с причиной и
комментарием для текущей озвучки. Для жалоб на истории NPC нужно расширение
0.6.35 или новее; жалоба сохраняет NPC ID.

Настройки персонажа и addon сохраняются в SavedVariables WoW и не требуют
доступа к серверной файловой системе. Если сервер поддерживает аккаунт
озвучки, код восстановления следует хранить как секрет пользователя и не
публиковать в Issue, логах или репозитории.

## Обновление

Правый клик по значку CatQuest у миникарты → «Написать нам»: ошибка,
предложение или другое сообщение с большим полем ввода. Команда `/cqcontact`
открывает ту же форму. Нужны аддон 0.10.66 и расширение 0.6.37 или новее.
Подробности: [обращения из игры](CONTACT.ru.md).

После сдачи квеста можно поставить ему 👍 или 👎 и отдельно пожаловаться на
озвучку в том же окне. Автоматическое окно отключается в `/cq options`:
«Предлагать оценить квест после сдачи». Изменить голос можно через `/cq rate`.
Подробности и API: [наш рейтинг квестов](QUEST-RATINGS.ru.md).

Обновите папку addon и расширение из доверенного релиза, затем перезагрузите
страницу игры. Локальные настройки не должны заменяться при обновлении.
