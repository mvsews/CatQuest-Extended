# Third-party материалы

## CatQuest

Оригинальный CatQuest содержит MIT-лицензию. Этот порт не включает Retail-реализацию целиком; в папке CatQuest оставлено независимое ядро для API 3.3.5a.

При подготовке порта использован оригинальный CatQuest 1.0.6 — Copyright (c)
2026 daniilcathey, MIT License,
https://www.curseforge.com/wow/addons/catquest. Страница проекта отдельно
указывает MIT для кода аддона и CC BY-NC-SA 4.0 для voice packs. С версии 0.10.0 порт повторяет
его набор настроек и команды (`/cq lore`, `/cq play`, `/cq h`, `/cq log`);
код написан заново под API 3.3.5a, исходники оригинала в архив не входят.

## CatQuest_Voices

Большой голосовой пак хранится отдельно и не входит в этот репозиторий. Для
него сохраняется лицензия CC BY-NC-SA 4.0, указанная на [странице проекта](https://www.curseforge.com/wow/addons/catquest-voices); текст лицензии — [официальная страница Creative Commons](https://creativecommons.org/licenses/by-nc-sa/4.0/). Полный пак не переиздается в этом маленьком MVP-архиве.

`tools/import_catquest_voicepack.py` можно запускать локально для подготовки
совместимых дорожек в `CatQuestExtended_Voices`. Сгенерированные `.ogg`
файлы игнорируются и не публикуются в этом репозитории. Производный
некоммерческий материал сохраняет лицензию CC BY-NC-SA 4.0 и атрибуцию в
`ATTRIBUTION.md`; полный архив оригинального пака сюда не переиздаётся.

## AiQuestVoice

Генераторы могут использовать локальные уже созданные файлы из внешнего
AiQuestVoice-источника. Этот источник, `.env` и API-ключи в публичный проект
не копируются.

## Исследованные реализации

- references/wow-questvoice — порт для 3.3.5a с MIT-лицензией;
- references/wow-voiceover — реализация с отдельной совместимостью для 3.3.5.

Из этих репозиториев в MVP не копировались библиотеки или аудио; они использованы как справочный материал по старому API.

## История зоны

`CatQuest/StoryData.lua` и `CatQuest/StoryTitles_*.lua` создаются скриптом
`tools/build_story.py` из двух источников:

- **CatQuest Codex 0.2.0** (daniilcathey, https://www.curseforge.com/wow/addons/catquest):
  группировка квестов классических зон в главы и русские названия глав
  (главы с пометкой `src c`). Код Кодекса не копировался, только эти данные.
  Страница CatQuest Codex сейчас указывает MIT для кода; для данных из версии
  0.2.0 сохраняем это происхождение и атрибуцию, не объявляя их собственным
  MIT-кодом.
- **AzerothCore** (https://github.com/azerothcore/azerothcore-wotlk, GPL-2.0):
  цепочки квестов остальных зон (Запределье, Нордскол, стартовые зоны
  эльфов крови и дренеев) и названия квестов на ruRU, zhCN, zhTW и enUS.
- **TrinityCore** (https://github.com/TrinityCore/TrinityCore, GPL-2.0):
  отдельный TDB 3.3.5a используется для сравнения квестов и поиска различий
  между двумя ядрами. Исходные SQL-дампы и собранный SQLite-каталог не входят
  в git и скачиваются скриптом `tools/sync_quest_catalog.py`.

Сгенерированные таблицы с NPC, квестами, локализациями и цепочками не следует
помечать общей MIT-лицензией автоматически: они содержат данные из ядер и/или
тексты игры. Для опубликованных артефактов источники и границы лицензий указаны
в [NOTICE.md](NOTICE.md); локальные SQLite-дампы и исходные SQL-файлы в public
репозиторий не входят.

## Книги, записки и лор мест

`CatQuest/BookData.lua` собирается скриптом `tools/build_books.py` из
**CatQuest Books 0.6.4** (daniilcathey,
https://www.curseforge.com/wow/addons/catquest-books, CC BY-NC-SA 4.0):
длительности, субтитры, связь «название книги и страница → запись». Озвучка
(2 399 OGG, рассказчик, ruRU) не входит в этот репозиторий и распространяется
отдельно.
Пак распространяется под CC BY-NC-SA 4.0, как и CatQuest Voices; этот порт
некоммерческий, авторство сохраняется.
